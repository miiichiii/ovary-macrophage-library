Morris 2022 Ovary Explorer — public read-only web viewer

English
Open the website in a current browser. No sign-in, ZIP download, Tailscale, or Mac Studio is needed. Internet is needed to load the page and gene data. Use Language to switch English/Japanese. Choose a saved cluster or analysis to open it below the parent; enter genes such as Mafb, Alox15 to display expression. Each expression panel has a color scale and range. Only previously computed analyses are available; new clustering/UMAP is not supported. This is a dated snapshot, not automatically synchronized.

日本語
最新のブラウザーでURLを開いてください。ログイン、ZIPのダウンロード、Tailscale、Mac Studioは不要です。画面と遺伝子データの読み込みにはインターネット接続が必要です。Languageで日英を切り替えます。保存済みクラスターや解析を選ぶと親の下に開きます。Mafb, Alox15などを入力すると発現を表示し、配色や範囲を変更できます。新規クラスタリング・UMAP計算はできません。保存時点の閲覧版で、その後の解析は自動追加されません。

54,748 cells; 25,289 genes; 14 saved analyses.
Source: Morris et al., eLife 2022;11:e77239. https://doi.org/10.7554/eLife.77239
Snapshot: 2026-10-31.
The large interoperable h5ad backup remains in the original Drive ZIP, not this web deployment.

Library edition: defaults to macrophage candidates QC1377. A valid ?run= ID opens any of the 14 saved analyses. Unknown run IDs fall back to QC1377. ?lang=ja or ?lang=en sets the display language. The QC1377 annotation is a candidate designation, not definitive macrophage identification.
